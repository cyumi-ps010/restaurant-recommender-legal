# Restaurant Recommender プライバシーポリシー

制定日：2026年9月27日
最終更新日：2026年9月27日

## 1. 対象

本ポリシーは、開発者本人がローカル環境で利用するRestaurant Recommender
（以下「本アプリ」）と、利用規約等を掲載する本公開サイトにおける
情報の取扱いを説明します。

## 2. 本アプリで扱う情報と目的

本アプリは、入力された場所の文字列、検索中心の緯度・経度、検索半径、
訪問日時、利用人数、予算、ジャンル、雰囲気、利用目的、避けたい条件、
自由文をローカル環境で扱います。

これらの入力と取得した店舗情報を、候補取得、入力確認、条件判定、
結果表示および動作確認に使用します。
現在、自由文の内容を解釈して検索や判定に利用する機能はありません。

端末のGPS等による現在地の自動取得は行いません。
Phase 2の観察では公共地点の座標を使用し、氏名、連絡先、自宅住所などの
個人を特定する情報は入力しません。

## 3. Googleへの送信

実店舗検索を実行すると、検索中心の緯度・経度と検索半径を、
固定の検索設定とともにGoogle Maps PlatformのPlaces API (New)へ送信します。
固定設定には、飲食店の検索、日本語表示、地域コードJP、距離順、
最大20件などが含まれます。認証用のAPIキーも送信します。

場所の文字列、訪問日時、利用人数、予算、ジャンル、雰囲気、利用目的、
避けたい条件、自由文は、Places APIのリクエストには含めません。

Googleは、送信した情報や通信に伴うIPアドレスなどを取得・利用する場合があります。
Googleによる情報の利用・保持には、
[Googleプライバシーポリシー](https://policies.google.com/privacy)が適用されます。
本ポリシーは同文書を参照により組み込みます。

## 4. 本アプリ側での保存

本アプリには、入力内容や実API応答をファイル・データベース・ログへ
永続保存する機能はありません。処理・表示に必要な情報は、
ローカル環境のメモリや画面上で一時的に扱います。

Phase 2の観察記録には、個人入力や実店舗を特定する情報を含めず、
件数などの集計と所見のみを残す方針です。
生のAPI応答、店舗名・ID・住所・座標を観察記録として保存しません。

この保存方針は本アプリと観察記録に関するものであり、
Googleなどの外部事業者による記録・保持とは別です。

## 5. 実行基盤・公開サイト・外部リンク

本アプリは画面表示にStreamlitを使用します。
Streamlitの利用統計送信は実行環境の設定に依存します。
詳細は[Streamlitの利用統計に関する説明](https://docs.streamlit.io/develop/concepts/configuration/options#telemetry)
をご確認ください。

本公開サイトはGitHub Pagesで配信します。
GitHubは、ログインの有無にかかわらず、閲覧者のIPアドレスを
セキュリティ目的で記録・保持します。
詳細は[GitHubプライバシーステートメント](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)
をご確認ください。

本アプリや本公開サイトからGoogle Mapsなどの外部リンクを開いた場合、
リンク先への通信が発生し、そのサービスの規約・プライバシーポリシーが適用されます。

## 6. 変更

情報の取扱いを変更する場合は、変更内容に合わせて本ポリシーを更新します。
