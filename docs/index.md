# Restaurant Recommenderについて

Restaurant Recommenderは、開発者本人がローカル環境で利用する、
レストラン候補の取得・条件判定を確認するための個人開発アプリです。
現在、一般向けのアプリ提供は行っていません。

このサイトでは、本アプリの利用規約とプライバシーポリシーを公開しています。

- [利用規約](./terms.html)
- [プライバシーポリシー](./privacy.html)

本アプリは、実店舗情報の取得にGoogle Maps PlatformのPlaces API (New)を使用します。
店舗情報に対する条件判定は、本アプリが行うものです。
